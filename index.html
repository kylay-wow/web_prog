About this coursework

This portfolio is built as part of my Web Development module, focused on HTML, CSS and JavaScript fundamentals. Each week introduces a new concept — from semantic markup through responsive layout to DOM manipulation and events — and the guides and exercises on this site are my practice work for that topic.

The site itself is hand-written with semantic HTML5 and plain CSS3: no frameworks and no build tools, so every page stays easy to read, mark and extend as the course progresses.
