03 — Improvements Implemented

01. Colour Contrast

Changed the foreground text colour from #777 to #595959 to improve contrast against the existing background.

Before

.site-footer {
    text-align: center;
    padding: 25px 20px;

    color: #777;
    font-size: 0.9rem;

    border-top: 1px solid #ddd;
}

After

.site-footer {
    text-align: center;
    padding: 25px 20px;

    color: #595959;
    font-size: 0.9rem;

    border-top: 1px solid #ddd;
}

Used a darker foreground colour to improve text contrast and make event information easier to read.

02. HTML List Structure

Moved the list divider and exercise items inside the unordered list to ensure all list items are correctly contained within their parent ul element.

Before

<ul>
        <li>Exercise 1</li>
      </ul>

      <li class="day-divider">
        JS Form Validation
      </li>

      <ul>
        <li>Exercise 2</li>
      </ul>

After

<ul>
        <li>Exercise 1</li>

        <li class="day-divider">
          JS Form Validation
        </li>

        <li>Exercise 2</li>
      </ul>

Fixed the HTML hierarchy by keeping all list items within one unordered list, resulting in more valid and meaningful HTML structure.
