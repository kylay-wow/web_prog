02 — Areas for Improvement

Colour Contrast

Some text and background combinations had insufficient contrast, making information harder to read.

Addressed

ARIA Attribute Errors

Some ARIA roles and attributes were not appropriately matched. Filter controls also required more suitable ARIA states and accessible labels.

Addressed

HTML Semantics

Some structural elements used generic div elements instead of more meaningful HTML elements, such as section and heading elements.

Addressed

03 — Improvements Implemented

01. Colour Contrast

Changed the text colours of the page subtitle, filter buttons, event type buttons and event metadata to darker colours.

Before


      .page-sub {
          color: #5B82E0;
      }

      .forum-tab {
          color: #5B82E0;
      }

      .events-type-btn {
          color: #5B82E0;
      }

      .event-card-meta {
          color: #5B82E0;
      }

After

.page-sub {
          color: #0E2466;
      }

      .forum-tab {
          color: #0E2466;
      }

      .events-type-btn {
          color: #0E2466;
      }

      .event-card-meta {
          color: #0E2466;
      }

Improved text readability by using darker text colours against the existing backgrounds.

02. ARIA Attributes — HTML

Updated the ARIA roles and states of the time filter buttons, removed unnecessary labels from points badges and added descriptive labels to RSVP buttons.

Before

<div role="tablist"
        aria-label="Event time filter">

      <button role="tab"
              aria-selected="true">
        Upcoming
      </button>

    </div>

    <span aria-label="Earn 60 points">
      +60 pts
    </span>

After

<div role="group"
        aria-label="Filter events by time">

      <button aria-pressed="true">
        Upcoming
      </button>

    </div>

    <span>+60 pts</span>

    <button
      aria-label="RSVP for hiking trip">
      RSVP
    </button>

Used more appropriate ARIA roles and states, while providing additional context for RSVP buttons.

03. ARIA Attributes — JavaScript

Restricted the time filter selector so that JavaScript updates only the filter buttons instead of also selecting the event cards.

Before

const timeTabs =
      document.querySelectorAll(
        '[data-filter]'
      );

After

const timeTabs =
      document.querySelectorAll(
        '.forum-filter-tabs button[data-filter]'
      );

Prevented the filter script from applying tab-related ARIA states to event cards that are not tab elements.

04. Semantic HTML Elements

Replaced generic structural div elements with more meaningful HTML elements for the events listing and event headings.

Before

<div class="events-grid">

      <div class="event-card-title">
        Hiking Trip
      </div>

    </div>

After

<section class="events-grid">

      <h2 class="event-card-title">
        Hiking Trip
      </h2>

    </section>

Improved the document structure and made the content easier for assistive technologies to interpret.
