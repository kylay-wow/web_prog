02 — Areas for Improvement

Colour Contrast

Text and background combinations did not provide sufficient contrast, making content difficult for some users to read.

Addressed

Missing Image Alternative Text

Images lacked descriptive alt attributes, preventing screen reader users from understanding meaningful images.

Addressed

Form Labels

Some form inputs did not have properly associated labels, making their purpose unclear to assistive technologies.

Addressed

Non-semantic Interactive Elements

Some clickable div elements were used instead of native buttons, limiting expected keyboard interaction.

Addressed

ARIA Attribute Errors

Incorrect or invalid ARIA attributes can cause accessible names, roles or relationships to be interpreted incorrectly.

Addressed

Keyboard Accessibility

Interactive elements need to be reachable and usable through keyboard navigation, with visible focus indicators.

Addressed

03 — Improvements Implemented

01. Colour Contrast

Changed low-contrast text colours to darker colours.

Before

color: #5B82E0;
background: #FFFFFF;

After

color: #0E2466;
background: #FFFFFF;

Increased text contrast to meet the WCAG AA 4.5:1 requirement for normal-sized text.

02. Image Alternative Text

Added descriptive alt attributes to meaningful images.

Before

<img src="event.jpg">

After

<img
  src="event.jpg"
  alt="Students at a campus event"
>

Alternative text communicates meaningful image content to screen reader users.

03. Form Labels

Associated labels with their corresponding input fields.

Before

<input
  type="email"
  placeholder="Email"
>

After

<label for="email">
  Email
</label>

<input
  type="email"
  id="email"
>

Explicit label associations help assistive technologies identify the purpose of form inputs.

04. Semantic Buttons

Replaced generic clickable div elements with native buttons.

Before

<div onclick="filterEvents()">
  Filter
</div>

After

<button
  type="button"
  onclick="filterEvents()"
>
  Filter
</button>

Native buttons provide built-in keyboard support and communicate their interactive role.

05. ARIA Attribute Errors

Corrected invalid ARIA relationships and accessible names.

Before

<button
  aria-labelledby="missing-title"
>
  Submit
</button>

After

<button
  aria-label="Submit form"
>
  Submit
</button>

Ensured ARIA attributes reference valid elements and provide accessible names where needed.

06. Keyboard Navigation

Added a skip link, navigable section links and visible focus states.

Before

/* No visible focus
   styling */

After

a:focus-visible {
  outline: 3px solid #174FBC;
  outline-offset: 4px;
}

Users can navigate the report using Tab and Shift + Tab while seeing which link currently has keyboard focus.
